# InvestTrack - Stock Portfolio Tracker

Single Page Application sviluppata con Streamlit per il tracciamento del portafoglio azionario.

## Funzionalità
- Calcolo PMC Ponderato
- P&L Realizzato e Latente
- Supporto Multivaluta (Conversione automatica in valuta portafoglio)
- Analisi FOMO sulle vendite
- Export/Import dati via CSV

## Installazione
Assicurati di avere il virtual environment attivo.

```bash
pip install -r requirements.txt
```

## Avvio
Per avviare l'applicazione esegui:

```bash
streamlit run app.py
```
